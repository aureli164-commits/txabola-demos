# TXABOLA — démos

Démos statiques installables sur iPhone (Safari › Partager › Sur l'écran d'accueil).

| Dossier | Projet Vercel | Contenu |
|---|---|---|
| `ticketemoin/` | `ticketemoin-demo` | Prototype Ticketémoin (données fictives, stockage local) |
| `validee/` | `validee-demo` | Démo Val'idée, 5 métiers (données fictives, stockage local) |

Règles :
- Ce dépôt est isolé : aucun lien avec `sauvage-os` (Intendance) ni Cotéquip.
- Chaque dossier = un projet Vercel distinct, Root Directory = le dossier, sans framework ni build.
- Aucune donnée réelle, aucun secret, aucune variable d'environnement.
